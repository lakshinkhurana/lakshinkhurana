## 🚀 Featured Projects

### 🔹 [Music Transformer](https://github.com/lakshinkhurana/music-transformer)
A from-scratch reimplementation of the Music Transformer paper, trained on 100K+ MIDI tokens in PyTorch to generate original Bach-style compositions (loss 1.83, perplexity 6.26).
- Custom relative self-attention built from the ground up
- Full MIDI tokenization, training, and generation pipeline

<img src="https://github-readme-stats.vercel.app/api/pin/?username=lakshinkhurana&repo=music-transformer&theme=radical"/>

### 🔹 [NanoGPT](https://github.com/lakshinkhurana/nanoGPT)
A character-level GPT trained on Shakespeare to understand transformer internals end to end.
- Implemented tokenization, dataset prep, and the training loop from scratch
- Experimented with scaling and optimization techniques

<img src="https://github-readme-stats.vercel.app/api/pin/?username=lakshinkhurana&repo=nanoGPT&theme=radical"/>

- Reduced manual intervention across recurring processes
